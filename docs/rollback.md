# Откат на прежнюю версию

Бэкап делается автоматически при каждом `bash ~/regru.sh deploy`. Путь архива скрипт печатает в конце.

```bash
ssh u3629668@server274.hosting.reg.ru

# список бэкапов, свежие сверху
ls -1t ~/backups/bazaimporta-*.tar.gz | head -5

# откат: текущая папка сайта переименовывается в *.failed-<время> (не удаляется), архив разворачивается на её место,
# затем автоматическая проверка сайта
bash ~/regru.sh rollback ~/backups/bazaimporta-ГГГГММДД-ЧЧММСС.tar.gz
```

Когда убедитесь, что откат в порядке, отложенную папку `*.failed-*` можно удалить вручную.

Правки, которые были на проде до редизайна, лежат также в git-ветке `prod-snapshot-…` в репозитории на сервере
(`git branch --list 'prod-snapshot-*'`).
