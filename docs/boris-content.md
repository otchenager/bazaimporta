# Борис — инвентаризация контента

## Где и что
- **Репозиторий:** github.com/otchenager/bazaimpotraAI, локальная копия `C:\projects\BAZA\bazaimpotraAI`.
- **Бот:** @bazaimporta_bot — тот же бот, что принимает оплату. Отдельного бота «Бориса» нет.
- **Стек:** Node 20+ (ESM), grammY (long polling), Express (вебхук Robokassa `POST /robokassa/result`), PostgreSQL (`pg`), node-cron.
- **Точка входа:** `index.js` — HTTP-сервер, крон, профиль бота, затем `bot.start()`.
- **Деплой:** Railway (`db/index.js` различает `*.railway.internal`), переменные — в Railway → Variables, шаблон — `.env.example`.
  - БД, судя по `.env.local` от Vercel CLI, — Neon Postgres.
  - Автодеплой при пуше в `main` — по брифингу «рекомендовано», в коде не подтверждено. Ветку `boris-start-flow` не пушил.
- **ИИ / LLM:** нет. В коде нет вызовов OpenAI, Anthropic или OpenRouter, нет системного промпта, RAG и базы знаний.
  - «ИИ-агент» — только текст приветствия. Бот работает как меню с кнопками и фиксированными ответами.
- **Расписание:** `src/cron.js`.
  - Ежедневно в 03:00 — снятие истёкших подписок (бан и разбан в закрытом канале).
  - По понедельникам в 09:00 — отчёт о выплатах партнёрам.
  - Постов по расписанию нет.
- **Где живут тексты:**
  - `src/texts.js` (новый) — описание бота и сценарий /start;
  - `src/bot.js` — меню и ответы;
  - `src/server.js` — сообщение после оплаты;
  - `src/cron.js` — уведомления;
  - `db/schema.sql` — название тарифа;
  - картинки «О нас» — в `assets/`.

## Как подключить кружок и полное видео
Бот сам загрузить файл больше 50 МБ не может, ролик весит 438 МБ. Поэтому файлы один раз загружаются через обычный Telegram:
1. Задеплоить ветку `boris-start-flow`.
2. С аккаунта `ADMIN_TELEGRAM_ID` отправить боту ролик как видео (не файлом). Бот ответит строкой `BORIS_VIDEO_FILE_ID=…`.
3. Записать кружок прямо в чате с ботом (зажать кнопку камеры). Бот ответит `BORIS_NOTE_FILE_ID=…`.
4. Вставить обе строки в Railway → Variables и перезапустить сервис.

Пока переменных нет, /start показывает только оффер; кружок и видео пропускаются без ошибки.
