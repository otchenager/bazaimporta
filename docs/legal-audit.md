### Куда попадают данные заявки (факт по коду)

1. **CSV на хостинге reg.ru, РФ** — `~/leads/leads.csv`, вне веб-корня. Пишется первым; без успешной записи заявка не принимается (500).
2. **Письмо** через `mail()` хостинга на `kirill.malin0vsky@yandex.ru` (Яндекс Почта, РФ).
3. **Кабинет заявок** `/manager/` — читает тот же CSV на reg.ru, вход по паролю. Статусы — `~/leads/status.json`, журнал удалений — `~/leads/deletions.log` (без ПДн).
4. **Telegram Bot API** (`api.telegram.org`, серверы за рубежом) → личка @visagevvvv: с 13.10.2026 **только уведомление** (трек, время, ссылка на кабинет), без ПДн — трансграничной передачи нет.
5. Служебное: `~/leads/state/` (sha256 от IP для rate limit, ключи идемпотентности, сутки), `error_log` хостинга (IP при отсеве спама), `telegram-failed.log` / `mail-failed.log` (время и ключ заявки, без ПДн).
6. **Яндекс Метрика** (ООО «Яндекс», РФ) — cookie и поведение; после изменений — только с согласием.
7. Обращения субъектов на email из футера — Gmail (Google LLC, США), это тоже трансграничная передача, если пользователь пишет туда (см. плейсхолдеры).
