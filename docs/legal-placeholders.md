# Что владелец должен заполнить в юридических документах

<!-- ТРЕБУЕТ ПРОВЕРКИ ЮРИСТОМ -->

Все значения — в одном файле `frontend/src/legal/requisites.js`. Пока там есть `[…]`, `node scripts/check-copy.mjs --release` падает, а на сайте плейсхолдеры видны как есть (в футере, политике, оферте). **В прод с плейсхолдерами не выпускаем.**

| Поле | Что вписать | Где видно |
|---|---|---|
| `REQUISITES.address` | Почтовый адрес с индексом для претензий и запросов по ПДн (можно адрес регистрации ИП) | футер, все документы, `/rekvizity/` |
| `PD.retention` | Срок хранения заявок, например «1 год с момента получения заявки» | `/privacy/` §8, `/consent/` §5 |
| `PD.responsible` | ФИО ответственного за обработку ПДн (у ИП обычно он сам) | `/privacy/` §11 |
| `PD.startDate` | Дата начала обработки ПДн (запуск лид-формы) | уведомление в РКН (`docs/rkn-notification.md`) |
| `EDITION` | Дата редакции документов, например `13.10.2026` | шапка каждого документа |

## Когда меняется текст документа

Поднять версию в `VERSIONS` (`requisites.js`):
- `cookies` — баннер покажется всем снова, Метрика не стартует до нового согласия;
- `pd`, `ads` — новая версия пишется в CSV с каждой заявкой (доказательство, с какой редакцией согласился человек).
