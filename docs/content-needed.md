В продакшен-сборке эти поля **скрыты** (посетитель не видит заглушек). Посмотреть их на месте: `npm run dev`
или сборка с `VITE_SHOW_TODO=1`. Правка — в `frontend/src/content/copy.js` / `tracks.js` (+ `docs/copy.md`).
