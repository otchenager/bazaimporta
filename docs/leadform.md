## Настройка сервера (reg.ru, один раз)
PHP должен исполняться в веб-корне. Проверка: `php -v` по SSH. Отсюда порт 22 сервера недоступен, поэтому проверку нужно сделать вручную.

```bash
mkdir -p ~/config ~/leads && chmod 700 ~/config ~/leads
nano ~/config/lead-config.php      # шаблон: deploy/lead-config.example.php (BOT_TOKEN, CHAT_ID)
chmod 600 ~/config/lead-config.php
```

Что где лежит:
- `~/config` и `~/leads` — в домашней папке, выше веб-корня (`~/www/bazaimporta.ru`), по HTTP недоступны.
- Заявки — `~/leads/leads.csv`: UTF-8 с BOM, разделитель `;`, открывается в Excel.
- Сбои Telegram — `~/leads/telegram-failed.log`.
- Rate limit и ключи идемпотентности — `~/leads/state/`.

Проверки после выкладки:
- Письмо: тестовая заявка «ТЕСТ …» приходит на kirill.malin0vsky@yandex.ru с темой «[ТЕСТ] Заявка с сайта: …». Если её нет во «Входящих» — проверьте «Спам». Если и там нет — `mail()` на хостинге выключен, или для домена нужен ящик `noreply@bazaimporta.ru` (создаётся в панели reg.ru → Почта).
- `curl -s https://bazaimporta.ru/api/lead.php` → `{"ok":false,"error":"method"}` (405), больше ничего не раскрывается.
- Тестовая заявка с именем «ТЕСТ …» приходит в Telegram с пометкой 🧪 ТЕСТ, а в CSV в колонке `test` стоит 1.

Ветка: `deploy/regru.sh` по умолчанию берёт `redesign`. Чтобы выложить эту ветку: `BRANCH=leadform-video bash ~/regru.sh deploy` (или сначала смержить её).

## Антиспам и надёжность (без капчи)
- **Honeypot** — скрытое поле `website`.
- **Время заполнения:** от загрузки страницы до отправки нужно минимум 3 с.
- Боту на обе проверки отвечаем `{ok:true}`, но заявку не сохраняем — чтобы бот не подбирал обход.
- **Rate limit:** 5 заявок за 10 минут с одного IP, дальше 429.
- **Идемпотентность.** Ключ живёт в sessionStorage. Двойной клик или ретрай после сбоя сети не создают дубль.
  - Если CSV не записался, ключ освобождается, и повтор заявку не теряет.
- **Ошибки:** наружу уходит только код (`method`, `content_type`, `invalid:name,phone`, `rate_limited`, `server`). PHP-предупреждения пишутся в `error_log`.
- Чужой `Origin` → 403.

## Видео
- **Исходник:** 24 мин, 1280×720, 50 к/с, со звуком, 438 МБ. В git не попадает (`.gitignore`).
- **1080p не делали:** исходник 720p, апскейл только раздул бы файл.
- **Луп:** без звука, 25 к/с, 60 с; шов сглажен кроссфейдом 0,6 с. Кодирование в 2 прохода с целевым битрейтом.

Поведение:
- Постер — первый кадр лупа и LCP-элемент; виден сразу.
- `preload="none"`. Видео начинает грузиться после `load` и только когда hero на экране; уходит с экрана — пауза.
- Кнопка паузы — для WCAG 2.2.2.
- При `prefers-reduced-motion` и Save-Data показывается только постер.
- На телефоне порядок: заголовок → кнопки → видео. Оффер и обе CTA остаются в первом экране и читаются без затемняющей подложки. Видео фоном под текстом снижало бы контраст и смещало CTA.
