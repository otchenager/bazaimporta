|---|---|---|
| Ясность за 5 секунд | **10** | H1 в 6 слов «Привози авто из-за границы без переплат», одна строка подзаголовка, одна оранжевая кнопка, цифры 200+ / 0 ₽ / 4 — всё на первом экране 375px |
| Сегментация | **10** | «Кто ты?» сразу под hero: 3 карточки с фразой-болью от первого лица и реальным фото. У каждого трека своя страница с собственным H1, обещанием, пунктами, путём, кейсом и целью Метрики |

| Доверие | **7** | Есть: 24 реальных фото передачи машин, Huracán, ИП + ИНН + оферта у блока доверия, бесплатный вход без предоплаты. **Не хватает:** цифр в кейсах, имени и лица основателя, отзывов → `docs/content-needed.md` п. 1–4. Без реальных данных честно выше не поднять |
| Объём текста | **10** | Текста примерно в 3,5 раза меньше. Ни одного абзаца длиннее 110 знаков — правило проверяется `npm run lint` |
| Визуал | **9** | Строгая тёмная сетка, один акцент, крупная Oswald, реальные фото вместо стоков, без декоративных градиентов и эмодзи. −1: пока нет портрета основателя для героя блока доверия |
| 3D/эффекты | **9** | Собственный суперкар из 7 000 частиц: «въезжает» справа, объём за счёт двух бортов, поворот за курсором и скроллом, частицы разлетаются от курсора. 6,5 КБ JS, грузится после страницы, постер до этого. Наклон и блик карточек треков, бегущая точка на дорожной карте. −1: в треках реальные фото, а не отдельные 3D-модели (осознанно: бюджет производительности и доверие) |
| Мобильная версия | **10** | 375px: без горизонтального скролла, тап-цели ≥ 44px, safe-area у липкой кнопки, карточки треков компактные (3 трека на одном экране) |
| Производительность | **10** | Mobile 100, LCP 1,5 с, CLS ≤ 0,015, TBT ≤ 30 мс, вес 7,8 МБ → 0,4 МБ |
| Доступность | **10** | Lighthouse 100. Skip-link, фокус-кольца, `aria-current` на треках, FAQ на `<details>`, alt у всех фото, reduced-motion → без анимаций и WebGL |
